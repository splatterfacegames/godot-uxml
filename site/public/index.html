Unity UI files, running as Godot controls.

godot-uxml is a Godot 4.7 addon. It loads Unity UI Toolkit documents (UXML) and stylesheets (USS) and makes a real Godot control for each element. Make the UI in Unity or in UXML Editor; the same files run in Godot without changes.

Two implementations, one behaviour.

Each Unity control is made from the same part elements as in Unity, with a default theme of values measured in Unity 6000.3. Focus, keyboard and controller navigation, theme fonts and signals work as in any Godot UI.

Native core

A Rust GDExtension (godot-rust). It keeps style and layout data in Rust and places the controls directly. It loads automatically when godot_uxml_native.windows.x86_64.dll is in addons/godot_uxml/bin. The binary is for Windows x64 only for now.

GDScript path

The same behaviour without the binary: Linux, macOS and the web. The demo on this page runs this path in your browser.

Checked equal

Equivalence checks compare each optimized path with the original implementation, value by value: 0 differences in 5,929 checks on the native core and 5,694 on the GDScript path.

  • Incremental updates. A hover or a class change recomputes only the elements it can affect. A paint-only change does not run layout again.
  • Panel scaling. Unity's PanelSettings, from a resource or the .asset itself: the same scale as Unity on any screen, and text, borders and images drawn sharp at that scale.
  • Virtualized lists. ListView makes only the rows that fill the viewport and binds them again during a scroll.
  • Diagnostics with a position. Each unsupported feature gives one diagnostic with file, line and column. A malformed document still loads.
  • No code runs from a document. No Unity, Node.js or browser at runtime.

Performance

The native core against Unity UI Toolkit, with the same UXML and USS files and the same operations. A screen of 1,531 elements, 3 stylesheets of about 250 rules, var() and :hover/:focus rules, with the Unity default theme. Release builds of Godot 4.7.1 and Unity 6000.3.24f1 (IL2CPP). Intel Xeon W-2135, Windows 11. Medians (the loads: the quietest of five rounds on a shared machine).

Runtime v2 is an opt-in (UxmlDocument.runtime = 2): the native core draws the elements itself, with one Control only for each focusable or interactive element (and real text editors), loads these screens 1.5 to 5 times faster (the big screen 4.2 times), and updates them faster than the default runtime. Its document model is a native table: an element object is made only when something asks for it. A document it does not cover yet loads on the default runtime.

Editor APIs

Calls for tools such as a UXML editor. They take a UxmlElement, so elements without a name work too. UXML Editor is built on them. 

doc.load_source(text, path, "", resolver)   # read every file through a resolver
doc.get_control_for(element)                # also get_native_for, get_element_for
doc.explain_style(element, "margin-top")    # every declaration, winner first
doc.set_forced_states(element, PackedStringArray(["hover"]))
doc.get_transitions()                       # and seek_transitions(seconds)
doc.element_at(point)                       # deepest element at a point
doc.reload_stylesheet(origin, uss_text)     # restyle without a reload
doc.replace_source(uxml_text)               # edit in place when possible
UxmlControls.catalog()                      # elements and attributes
doc.set_drag_and_drop("list", callbacks)    # Unity drag-and-drop callbacks
doc.get_item_index_at("list", point)        # also get_item_rect("list", index)
doc.get_element_rect(element, space)        # rectangle in another element's space

Install

  1. Copy addons/godot_uxml into the addons folder of your Godot project.
  2. Open Project > Project Settings > Plugins.
  3. Enable godot_uxml.

Then add a UxmlDocument node to a scene and set uxml_path and project_root, or load a document from code. 

var doc := UxmlDocument.new()
add_child(doc)
doc.set_anchors_preset(Control.PRESET_FULL_RECT)
doc.load_document("ui.uxml", "res://ui")

doc.button_pressed.connect(func(name): print("pressed ", name))
doc.value_changed.connect(func(name, value): print(name, " = ", value))

for d in doc.diagnostics:
    print(UxmlDiagnostic.format(d))
